# NetWorkOS

> AI-powered collaborator memory built with **Antigravity CLI** and **Obsidian**.

NetWorkOS transforms natural language into a searchable engineering knowledge graph. Simply describe someone you've met, and it automatically extracts useful information, creates or updates collaborator notes, and links people with their skills, projects, technologies, and events.

## Features

* Natural language collaborator capture
* Automatic creation and updating of collaborator notes
* Obsidian wiki-link integration
* Connected graph of people, projects, skills, and events
* Searchable engineering network

## Example

**Input**

```text
I met Arun today. He's a 2nd-year CSE student at CIT, skilled in Java and Spring Boot, and interested in AI.
```

**Extracted Information**

* Collaborator: Arun
* College: CIT
* Year: 2nd Year
* Skills: Java, Spring Boot
* Interest: AI

NetWorkOS creates or updates the corresponding Obsidian note and links related entities automatically.

## Example Queries

* Who knows Docker?
* Who should I contact for AI?
* Who did I meet at the NEC workshop?
* Suggest teammates for a hackathon.
* Show everyone connected to Spring Boot.
